# Python Hotel Price Scraper CSV

This example demonstrates how to scrape hotel prices from a webpage and save them into a CSV file using Python. It utilizes the BeautifulSoup library to parse HTML content and extract hotel names and prices, simulating a real web scraping scenario. The extracted data is then stored in a spreadsheet-compatible CSV format using Python's built-in `csv` module.

## Language

`python`

## How to Run

1. Install BeautifulSoup: `pip install beautifulsoup4`
2. Run the script: `python main.py`
3. A CSV file named `hotel_prices_istanbul_YYYYMMDD.csv` will be created in the same directory.
